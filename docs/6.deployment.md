# 部署指南

## 概述

本文档介绍如何部署 ChronoFlow 分布式定时任务调度系统。

## 环境要求

### 基础环境

- Go 1.26.2+
- Node.js 18+ (前端开发)
- MySQL 8.0+
- Redis 7.0+
- Docker (可选)
- Docker Compose (可选)

### 系统要求

- CPU: 2 核+
- 内存: 4GB+
- 磁盘: 10GB+

## 部署方式

### 方式一：本地开发部署

#### 1. 克隆项目

```bash
git clone https://github.com/your-username/ChronoFlow.git
cd ChronoFlow
```

#### 2. 配置数据库

编辑 `config/config.yaml`：

```yaml
database:
  driver: mysql
  dsn: "root:123456@tcp(127.0.0.1:3306)/chronoflow?charset=utf8mb4&parseTime=True&loc=Local"

redis:
  addr: "127.0.0.1:6379"
  password: ""
  db: 0
```

#### 3. 初始化数据库

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE chronoflow CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 执行迁移
mysql -u root -p chronoflow < migrations/001_init.sql
```

#### 4. 启动后端

```bash
go run cmd/server/main.go
```

#### 5. 启动前端

```bash
cd web
npm install
npm run dev
```

### 方式二：Docker Compose 部署

#### 1. 克隆项目

```bash
git clone https://github.com/your-username/ChronoFlow.git
cd ChronoFlow
```

#### 2. 启动服务

```bash
# 启动基础服务（MySQL + Redis）
make docker-up

# 或启动所有服务（包含前端）
make docker-all
```

#### 3. 访问服务

- 后端 API: http://localhost:8080
- 前端界面: http://localhost:3000
- MySQL: localhost:3306
- Redis: localhost:6379

### 方式三：生产环境部署

#### 1. 构建二进制

```bash
make build-backend
```

#### 2. 构建前端

```bash
make build-frontend
```

#### 3. 部署后端

```bash
# 复制二进制和配置
cp bin/chronoflow /usr/local/bin/
cp config/config.yaml /etc/chronoflow/

# 创建 systemd 服务
sudo tee /etc/systemd/system/chronoflow.service <<EOF
[Unit]
Description=ChronoFlow Task Scheduler
After=network.target

[Service]
Type=simple
User=chronoflow
Group=chronoflow
ExecStart=/usr/local/bin/chronoflow
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable chronoflow
sudo systemctl start chronoflow
```

#### 4. 部署前端

```bash
# 复制前端文件
cp -r web/dist /var/www/chronoflow

# 配置 Nginx
sudo tee /etc/nginx/sites-available/chronoflow <<EOF
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/chronoflow;
    index index.html;

    location / {
        try_files \$uri \$uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
    }
}
EOF

# 启用站点
sudo ln -s /etc/nginx/sites-available/chronoflow /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 配置说明

### 完整配置文件

```yaml
# ChronoFlow 配置文件

server:
  port: 8080
  mode: debug  # debug | release | test

database:
  driver: mysql
  dsn: "root:123456@tcp(127.0.0.1:3306)/chronoflow?charset=utf8mb4&parseTime=True&loc=Local"
  max_open_conns: 100
  max_idle_conns: 10
  conn_max_lifetime: 3600  # 秒

redis:
  addr: "127.0.0.1:6379"
  password: ""
  db: 0
  pool_size: 10

scheduler:
  scan_interval: 5  # 扫描间隔（秒）
  batch_size: 100   # 每批扫描任务数

executor:
  timeout: 30       # HTTP 回调超时时间（秒）
  max_retries: 3    # 最大重试次数
  worker_pool_size: 10  # 工作池大小

retry:
  strategy: exponential  # exponential | fixed
  initial_interval: 10   # 初始重试间隔（秒）
  max_interval: 60       # 最大重试间隔（秒）
  multiplier: 3.0        # 指数退避倍数

log:
  level: info  # debug | info | warn | error
  format: json  # json | console
  output: stdout  # stdout | file
  file_path: ./logs/chronoflow.log
```

### 配置项说明

#### server

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| port | 服务端口 | 8080 |
| mode | 运行模式 | debug |

#### database

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| driver | 数据库驱动 | mysql |
| dsn | 数据库连接字符串 | - |
| max_open_conns | 最大打开连接数 | 100 |
| max_idle_conns | 最大空闲连接数 | 10 |
| conn_max_lifetime | 连接最大生命周期 | 3600 |

#### redis

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| addr | Redis 地址 | 127.0.0.1:6379 |
| password | Redis 密码 | - |
| db | Redis 数据库 | 0 |
| pool_size | 连接池大小 | 10 |

#### scheduler

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| scan_interval | 扫描间隔（秒） | 5 |
| batch_size | 每批扫描任务数 | 100 |

#### executor

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| timeout | HTTP 回调超时时间（秒） | 30 |
| max_retries | 最大重试次数 | 3 |
| worker_pool_size | 工作池大小 | 10 |

#### retry

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| strategy | 重试策略 | exponential |
| initial_interval | 初始重试间隔（秒） | 10 |
| max_interval | 最大重试间隔（秒） | 60 |
| multiplier | 指数退避倍数 | 3.0 |

### Prometheus 监控

ChronoFlow 集成了 Prometheus 监控，提供以下指标：

| 指标名 | 类型 | 说明 |
|--------|------|------|
| `chronoflow_task_exec_total` | Counter | 任务执行总数（按状态分类） |
| `chronoflow_task_exec_duration_seconds` | Histogram | 任务执行延迟分布 |
| `chronoflow_task_exec_success_total` | Counter | 任务执行成功总数 |
| `chronoflow_task_exec_failed_total` | Counter | 任务执行失败总数 |
| `chronoflow_task_exec_retry_total` | Counter | 任务重试总数 |
| `chronoflow_task_trigger_total` | Counter | 任务触发总数 |

#### Prometheus 配置

创建 `prometheus.yml` 配置文件：

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'chronoflow'
    static_configs:
      - targets: ['localhost:8080']
    metrics_path: '/metrics'
```

#### Grafana Dashboard

导入以下 PromQL 查询创建 Dashboard：

```promql
# 任务执行成功率
rate(chronoflow_task_exec_success_total[5m]) / rate(chronoflow_task_exec_total[5m])

# 任务执行失败率
rate(chronoflow_task_exec_failed_total[5m]) / rate(chronoflow_task_exec_total[5m])

# 任务重试率
rate(chronoflow_task_exec_retry_total[5m]) / rate(chronoflow_task_exec_total[5m])

# P50 延迟
histogram_quantile(0.50, rate(chronoflow_task_exec_duration_seconds_bucket[5m]))

# P99 延迟
histogram_quantile(0.99, rate(chronoflow_task_exec_duration_seconds_bucket[5m]))
```

### 监控指标

- 任务执行成功率
- 任务执行延迟
- 系统资源使用

## 故障排查

### 常见问题

#### 1. 数据库连接失败

检查数据库配置和连接字符串：

```bash
mysql -u root -p -e "SELECT 1;"
```

#### 2. Redis 连接失败

检查 Redis 服务状态：

```bash
redis-cli ping
```

#### 3. 任务不执行

检查任务状态：

```sql
SELECT id, name, status, next_trigger_time FROM tasks WHERE status = 'ENABLED';
```

#### 4. 任务执行失败

查看执行记录：

```sql
SELECT * FROM task_executions WHERE status = 'FAILED' ORDER BY created_at DESC LIMIT 10;
```

### 日志查看

```bash
# 查看实时日志
tail -f logs/chronoflow.log

# 查看错误日志
grep "error" logs/chronoflow.log
```
